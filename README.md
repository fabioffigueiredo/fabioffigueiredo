## Como leio os projetos

- **Evidência antes de aparência:** uma interface só entra como prova quando o caminho de execução, a origem e o limite podem ser verificados.
- **Métrica com protocolo:** um número público precisa carregar ambiente, método e o que ele não mede.
- **Confidencialidade por padrão:** detalhes de empregador, cliente e dados internos ficam fora dos repositórios e das demonstrações.
